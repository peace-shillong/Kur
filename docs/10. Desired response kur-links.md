### 2. Architecture Update: The Cascading Pipeline

The data retrieval pipeline for both **Wad-Kur** and **Bishar-Sang** now follows this exact waterfall order:

```
                                 │      User Query / Search        │
                                 └────────────────┬────────────────┘
                                                  │
                                                  ▼
                         ┌─────────────────────────────────────────────────┐
                         │   1. Device Cache (window.localStorage)         │
                         │   kur_cache_wadkur_* | kur_cache_bishar_*       │
                         └───────┬─────────────────────────────────┬───────┘
                                 │ Hit (< 2ms)                     │ Miss
                                 ▼                                 ▼
                     ┌───────────────────────┐   ┌─────────────────────────────────┐
                     │   Render in UI (0ms)  │   │  2. Compressed JSON Asset       │
                     └───────────────────────┘   │  /assets/commonSurnames.json    │
                                 ▲               └───────┬─────────────────┬───────┘
                                 │ Hit & Hydrate LS      │ Hit             │ Miss
                                 └───────────────────────┘                 ▼
                                                 ┌─────────────────────────────────┐
                                                 │  3. Local API & Cloudflare D1   │
                                                 │  Cloudflare Worker + Edge SQL   │
                                                 └───────┬─────────────────┬───────┘
                                                         │ Hit (40ms)      │ Miss
                                                         │ & Hydrate LS    ▼
                                                         │       ┌─────────────────┐
                                                         │       │ 4. Tynrai-AI    │
                                                         │       │ Upstream API    │
                                                         │       └────────┬────────┘
                                                         │                │ Write back
                                                         ▼                ▼
                                                 ┌─────────────────────────────────┐
                                                 │  5. Save to Cloudflare D1 SQL   │
                                                 │  6. Render UI & Hydrate Device  │
                                                 └─────────────────────────────────┘
```
