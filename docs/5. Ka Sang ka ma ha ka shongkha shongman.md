# Feature 2: Traditional Relationship Compatibility Checker
A fun, respectful, step-by-step interactive flow rooted in Khasi *Sang* (taboo/kinship) traditions to check if two people share clan ties.

## Mode:
This will have two modes, the first being a simple step-by-step form filling up process and the second mode will be a chat based step-by-step interaction.

## New Multi-Step Checking Flow
1. **Level 1 Check (Direct Maternal Clan Check):**
   - Input Person 1's surname and Person 2's surname.
   - Send `POST` request to the compatibility endpoint.
   - **Result Display:** Show a clear visual verdict (e.g., *"Related / Sang"* vs. *"No Direct Clan Link Found"*), displaying the exact relationship tier (*Ka juh ka kpoh*, *Ba ia dei kur*, etc.) if a match exists do not allow to proceed to next Level.
2. **Level 2 Check (Paternal / Other Parent's Clan Check):**
   - If Level 1 clears, prompt Person 1: *"Enter your father's / other parent's surname"* (*"Ka jait u kpa"*).
   - Run a secondary check comparing Person 1's paternal surname against Person 2's surname.
   - Display combined Level 1 + Level 2 relationship status clearly.
   - If Level 2 clears (or if the user wants a deeper check), Use will have to enter his/her maternal uncle's children's surname to check further and if level 2 doesn't clear then do not allow to proceed to next Level.

3. **Level 3 Check (Cousin Relation link Check):**
    - If Level 2 clears (or if the user wants a deeper check) prompt Person 1: *"Enter your maternal uncle's children's surname"* (*"Ka jait ki khun u kñii"*).
    - In the form it will be taken one surname at a time, if a comma separated list is given, then check for each surname, one after the other and give the results based on the number of surnames entered.
    - Display combined Level 1 + Level 2 + Level 3 relationship status clearly.
    - If level 3 doesn't clear then do not allow to proceed to next Level. Else if it clears show the Preview of Level 4.

### Option 2: Level Check by Chatting Method:
    App and user will interact like texting a chatbot.

    Message 1:
    App: Kane ka dei ka jait jong phi __________? / Is this your surname ________ ?
        - hooid
        - em 
    The App will use the primary surname of the user and display it in the question, then it will display buttons for response. If the user clicks "hooid" (Yes), the app proceeds to the next step. If "em" (No), the app will ask the user to enter their surname. 
    
    Message 2:
    App: Iathuh ka jait ba dei jong i paralok jong phi: / Please enter your friend's surname :
    User will enter and send the surname for checking

    After this the app does Level 1 Checking and shows the results like the "Checking by Form fillup method" shows from Level 1.

    Message 3: 
    App: Depending on results from Level 1. If the results is clear (meaning no direct clan link found) then it will proceed to the Level 2 else gives the message to the user that they should not proceed further in courtship.

    Level 2 Checking 
    Message 4: 
    App: Iathuh ia ka jait u kpa jong phi: / Enter your father's surname:
    User will enter and send the surname for checking
    
    Do Level 2 Checking
    Message 5: 
    App: Depending on results from Level 2. If the results is clear (meaning no link found) then it will proceed to the Level 3 else gives the message to the user that they should not proceed further in courtship.

    Level 3 Checking
    App: Iathuh ia ki jait jong ki khun jong ki mama jong phi baroh / Please enter the surnames of all your maternal uncle's children
    User: user will enter all his cousins surname, separated by comma "," if there are more than one. If the user does not have any maternal uncle, then the user will enter "Em" (No) or "0" (Zero).

    Message 6: 
    App: Depending on results from Level 3. If the results is clear (meaning no link found) then it will proceed to the Level 4 else gives the message to the user that they should not proceed further in courtship.

    Message 7:
    When a user reaches this stage, show the messages from Level 4. and tell them thank you and all the best.
